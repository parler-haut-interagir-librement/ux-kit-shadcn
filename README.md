# ux-kit-shadcn

Tailwind versions, in the style of the Shadcn kit, of the extra PHIL UX recipes, installed with `ux:install --kit=github.com/parler-haut-interagir-librement/ux-kit-shadcn`.

This repository is split from the PHIL monorepo, where it is developed; changes are made there.
